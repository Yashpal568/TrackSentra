# Roles & Permissions

## SUPER_ADMIN
Platform-level company/user/plan/system administration.

## COMPANY_ADMIN
Full administration inside one company.

## SITE_MANAGER
Manage assigned sites, guards, routes, checkpoints, shifts, and operational reports.

## SECURITY_SUPERVISOR
Monitor patrols, alerts, guards, and reports; limited configuration.

## GUARD
Access own patrols, scan assigned checkpoints, view own history, and trigger emergency alert.

Authorization must always be enforced by backend policy.
