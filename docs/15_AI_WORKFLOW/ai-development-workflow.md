# AI Development Workflow

## Before coding
1. Read AGENTS.md.
2. Read master roadmap.
3. Read current milestone.
4. Read module requirements.
5. Read database/API requirements.
6. Read UI/UX screen specification.
7. Inspect repository.

## During coding
- Implement the smallest coherent slice.
- Keep business logic server-side.
- Reuse components.
- Add tests alongside critical logic.
- Update docs when behavior changes.

## After coding
- Run tests.
- Run type checks/lint.
- Review tenant isolation.
- Review error states.
- Review responsive UI.
- Compare UI with approved design.
- Update milestone status only if acceptance criteria pass.
