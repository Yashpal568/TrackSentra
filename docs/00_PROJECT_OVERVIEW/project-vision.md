# Project Vision

## Problem
Industrial companies often cannot reliably verify whether guards physically completed required night patrol rounds. Manual registers and verbal confirmation provide weak real-time visibility.

## Solution
Security Patrol Management SaaS records patrol activity through physical checkpoints. Guards scan checkpoint QR codes from a mobile interface. The system records time, guard identity, patrol session, checkpoint sequence, GPS metadata, and validation status.

## Product promise
Give management an auditable view of patrol execution without requiring specialized tracking hardware for the MVP.

## Primary users
- SaaS super administrators
- Company administrators
- Site managers
- Security supervisors
- Security guards

## MVP
Multi-tenant company management, sites, guards, shifts, patrol routes, QR checkpoints, guard mobile/PWA flow, GPS validation at scans, real-time activity, alerts, reports, audit logs.

## Out of scope for MVP
Payroll, guard salary processing, unrelated HR functions, continuous background GPS tracking, advanced hardware integrations, and full payment/subscription automation.
