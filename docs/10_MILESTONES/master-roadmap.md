# Master Implementation Roadmap

## M01 Foundation
Repository, environments, code conventions, database connection, base UI shell.

## M02 Authentication & RBAC
Login, sessions, password flows, roles, permissions.

## M03 Multi-Tenant Company & Site
Companies, sites, tenant isolation, settings.

## M04 Guard & Shift Management
Guards, assignments, shifts, schedules.

## M05 Checkpoints & QR
Checkpoint CRUD, QR generation/identity, QR rotation.

## M06 Patrol Engine
Routes, ordered checkpoints, patrol sessions, state machine.

## M07 GPS Validation
Location permission, capture, backend distance/accuracy validation.

## M08 Guard PWA
Mobile journey and offline/network recovery behavior.

## M09 Live Monitoring
Realtime dashboard, active patrols, activity stream.

## M10 Alerts & Notifications
Exception detection, alert center, notification delivery.

## M11 Reports & Audit
Operational reports, exports, audit viewer.

## M12 Security & Hardening
Security testing, rate limits, tenant tests, observability, backups.

## M13 Production Launch
Staging acceptance, production deployment, monitoring, runbooks.

## M14 SaaS Monetization — Phase 2
Subscriptions, payment gateway, plan limits, invoices, renewal/suspension automation.
