# User Stories

## Company Admin
- As an admin, I can create sites.
- As an admin, I can create and assign guards.
- As an admin, I can configure patrol routes.
- As an admin, I can see patrol compliance.
- As an admin, I can investigate alerts.

## Supervisor
- As a supervisor, I can monitor active patrols.
- As a supervisor, I can see recent checkpoint scans.
- As a supervisor, I can respond to emergency alerts.

## Guard
- As a guard, I can log in.
- As a guard, I can see my assigned patrol.
- As a guard, I can scan a checkpoint.
- As a guard, I can see patrol progress.
- As a guard, I can request emergency assistance.

## Super Admin
- As a super admin, I can manage companies.
- As a super admin, I can monitor platform health.
- As a super admin, I can manage SaaS configuration.
